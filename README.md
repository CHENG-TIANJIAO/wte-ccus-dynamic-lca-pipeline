# Time-resolved and region-sensitive climate assessment of thirteen CO2 pathways for municipal waste incineration

Complete data and calculation chain behind the manuscript *"Time-resolved and region-sensitive climate assessment of thirteen CO2 capture, utilization and recycling pathways for municipal waste incineration"*.

Thirteen carbon-management pathways for one modal Japanese municipal solid waste
incinerator (300 t d-1, 84,000 t y-1) are harmonized onto a single explicit fossil-carbon
balance with cradle-to-grave-symmetric substitution credits, resolved across the ten
Japanese electricity supply regions, extended with a CO2 impulse-response climate layer,
and propagated through a shared-draw Monte Carlo analysis.

> **Scope.** This repository is self-contained. The default run reads only files shipped
> here and reproduces every number, table and figure in the manuscript except Figure 1,
> which is a schematic. Two optional provenance scripts re-derive shipped inputs from
> laboratory source workbooks that are not distributed; neither is needed for any result.

## What it computes

1. **Deterministic model** (`calculation_code/carbon_model.py`) - the single authoritative
   implementation of the fossil-carbon balance, reading every constant from
   `calculation_code/model_parameters.json`. No coefficient is duplicated anywhere else.
2. **Regional layer** (`regional_model.py`, `reconcile_regional.py`) - the 130 absolute
   pathway-region results and the 120 pairwise differences, reconciled against the
   national equation.
3. **Scenario decomposition** (`scenario_decomposition.py`, `regional_2050.py`) - the exact
   Shapley attribution of the 2025 to 2050 change over grid, waste carbon and hydrogen,
   across all eight background combinations.
4. **Climate layer** (`climate_response.py`, `build_climate.py`) - the CO2 impulse response
   and the cumulative radiative forcing of each pathway, validated against the closed-form
   integral of the same response.
5. **Uncertainty** (`monte_carlo.py`) - one 50,000-draw master matrix on which both
   chemical-recycling boundary treatments are evaluated, so any difference between them can
   only come from the boundary. 624 rank correlations.
6. **Hydrogen scenarios** (`hydrogen_scenarios.py`) - the three utilization pathways under
   five declared hydrogen-supply scenarios.
7. **Independent check** (`build_workbook.py`) - an Excel workbook that recomputes the
   governing equation from the raw input cells with live formulas, as a second
   implementation.

## Quickstart

```bash
cd calculation_code
python -m venv .venv && source .venv/bin/activate    # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python run_all.py
```

Python >= 3.11 with numpy, openpyxl and matplotlib; `calculation_code/requirements.txt`
pins the verified versions. No network access is needed. Expect roughly ten minutes on an
ordinary laptop, most of it in the Monte Carlo. Outputs are written to
`calculation_code/outputs/`; the reference copies shipped at the repository root are what
that run should reproduce.

## Expected results

| Check | Expected |
|---|---|
| Eq. 2 against Eq. 6, all 13 pathways | max abs difference 0 to 10 decimals (tolerance 1e-9 t) |
| Regional reconciliation, 130 absolute cells | max 0.000000 kt-CO2 per year |
| Shapley closure, 8 background combinations | 0 to 8 decimals |
| A/B draw difference for the 10 pathways the recycling boundary does not touch | exactly 0 |
| Workbook Eq. 2 sheet recomputed in Excel or LibreOffice | agrees with the model to 5e-7 t |
| 100-year cumulative forcing of a 1 kg CO2 pulse | 9.1721e-14 W m-2 y kg-1, against 9.1711e-14 for the closed-form integral, deviation 0.011 % |
| Static national result, reference plant / fuel-grade methanol | 18,737.1785 / -47,769.9264 t-CO2 per year |

Every CSV is regenerated byte for byte and the workbook is rebuilt with identical sheet
contents, formulas and computed values (only document-metadata timestamps differ). This was
verified by extracting the release into a clean directory and running it there with only the
files inside it. See [`docs/reproducibility.md`](docs/reproducibility.md).

`Unified_calculation_workbook.xlsx` is written programmatically, so it stores formulas but
no cached results. Open it in Excel or LibreOffice, which recalculate on open. A script that
reads it with openpyxl and `data_only=True` returns None for the formula cells by design.

## Layout

```
calculation_code/     the complete chain; run_all.py is the single entry point
  model_parameters.json      every model constant, read by carbon_model.py
  region_waste_carbon.csv    ten-region composition profiles
  regional_source/           prefecture profiles and the optional re-derivation script
*.csv, *.xlsx         reference result files the chain reproduces
docs/                 reproducibility, data dictionary, documentation/data licence
ZIP_VERIFICATION.md   SHA-256 of every entry of the archive accompanying the manuscript
TO_REVIEW_BEFORE_PUBLIC_RELEASE/   release gate to run before going public
```
